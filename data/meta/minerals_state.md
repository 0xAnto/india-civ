# minerals_state: value of mineral production and reporting mines by state, 2023-24

Files: data/normalized/minerals_state.json. Script: pipeline/build_minerals.py. Rows: 36; with data: 20 states.

## Source
Indian Minerals Yearbook 2024 (IBM), State Reviews tables 1 and 2. https://ibm.gov.in/writereaddata/files/177426215469c1178a48453IMYB_2024_EBookFinal.pdf
Check: the state values sum to 1,418,034,586 thousand Rs, equal to the India row.

## Caveats
Excludes fuel minerals, atomic minerals and minor minerals. States absent from the table are null. Value is Rs thousand (and Rs crore, computed).

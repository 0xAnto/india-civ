# minerals_points: mines, quarries and oil fields from Wikidata

Files: data/normalized/minerals_points.json. Script: pipeline/build_minerals.py (query is in pipeline/fetch_resources.py).

## Coverage
134 points: mostly items of type mine (about 119), quarry (7), oil field (7), coal deposit (1). Names missing for many. 4 points fall outside the state boundary polygons (state null).
There is no commodity field. This layer is a sample and not a mine register.
The Wikidata SPARQL service timed out on one broad query (all types matching a label regex). The query with a fixed list of type IDs works.
